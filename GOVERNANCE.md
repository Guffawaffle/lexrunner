# LexRunner stewardship

SmarterGPT was founded by Joseph Gustavson (Guffawaffle). Joseph is the initial
lead maintainer for this project. Contributions retain their authorship and
applicable ownership; maintainer status does not imply ownership of every contribution.

Changes use repository review and verification gates. Maintainers document material
architecture decisions in ADRs and discuss proposed changes through issues and pull
requests. Changes to governance follow that same public review process. Release
authority continues to follow the repository's release controls.

The code license permits commercial use and forks. [BRAND.md](BRAND.md) explains
truthful attribution and official project identity. The license grants no credentials,
tenant membership, company-data access or runtime execution authority.

AI-assisted contributions have the same review, rights-to-submit and provenance
requirements as other contributions. Do not make unsupported authorship, ownership
or licensing claims based on the use of an AI system.
