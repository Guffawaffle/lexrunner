# LexRunner 2.1.0 open-source release

- Status: **release candidate**
- Prepared: **2026-09-06**
- Supersedes: **2.0.2**

This minor release adopts Apache-2.0 and includes the previously merged immutable
authored-plan artifact contracts and service-level no-replace registration from
issue #947. The native acquisition, durable storage authority and plan-pinned
verifier work remain incomplete; observed artifacts cannot grant merge eligibility.
Execution receipts remain v2 and existing package exports stay compatible.

SmarterGPT was founded by Joseph Gustavson (Guffawaffle). Copyright and dependency
notices are preserved, including Lex's MIT license. Contribution, governance and
brand policies separate provenance from ownership and code rights from runtime
authority. Earlier immutable npm versions retain their applicable license terms.

The release updates fast-uri and qs to patched versions and treats PR branch names
and labels as data in the merged-branch cleanup workflow. Fork heads are rejected
before token-bearing cleanup steps.

## Publication boundary

Public package access is already enabled; this candidate is not yet published.
Publication still requires independent review, all release gates, the authorized
release-owner-signed commit and signed `lexrunner-v2.1.0` tag contained in main, and
the exact stable-tag GitHub OIDC workflow. No local agent publish command is authorized.
Preserved unrelated proof WIP is not included in the candidate commit or package.
