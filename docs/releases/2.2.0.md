# LexRunner 2.2.0 frozen-input release

- Status: **published on npm; public consumer verified**
- Prepared and published: **2026-09-09**
- Supersedes: **2.1.0**

This minor release adds an optional public frozen Git input contract while retaining
existing unbound plan support. Plan Schema 1.0.1 follows the repository's additive
optional-field patch rule; the package minor version identifies the new capability.
Consumers with older strict parsers must upgrade before reading bound plans.

Single-repository GitHub plans now capture repository identity, acquisition mode,
fully qualified source/target refs and exact commits. CLI and MCP local integration
use those commits through preparation, gates, merge and resume. Failed fetches never
fall back to local labels; moved inputs and mismatched checkouts fail explicitly.
Passing commands cannot conceal tracked/index/HEAD or integration-ref changes at
operation boundaries. Unexpected changes remain available for inspection.

Generated gate names resolve to actual commands. No default output paths are guessed;
explicit artifact requirements remain enforced. Gate and post-check receipts are
separate, and the plan JSON Schema export contains the full contract. The release
also refreshes vulnerable dependencies within declared ranges and improves first-use
and organization guidance. The Lex dependency remains deliberately pinned at 4.0.3.

## Evidence and limits

Source PR964 merged after independent review and required Ubuntu full test shards,
Windows bootstrap, Git-backed tests and packed consumers passed. The local frozen
fixture covers 20 real Git cases, including built CLI/MCP execution and mutation
regressions. Release PR965 received independent review and passed its required checks.

The [stable release workflow](https://github.com/SmarterGPT/lexrunner/actions/runs/34317496739)
published signed target `68ab6020f2bd4652e1b39791fc03cb484b3f61c8` after signature,
main-containment, full test, deterministic build and package checks passed. The
[GitHub release](https://github.com/SmarterGPT/lexrunner/releases/tag/lexrunner-v2.2.0)
and npm version 2.2.0 are public. A clean native Windows consumer fetched the public
tarball, matched its integrity to the release artifact and passed ESM/CJS exports,
CLI version/help and MCP surface checks. This is bounded consumer evidence, not
universal Windows qualification.

Frozen observations are not authenticated custody or protection from concurrent
hostile writers. Multi-repository plans remain legacy-unbound. No protected policy-host
service, authority activation or end-to-end remote integration is claimed. Exploratory
full default-suite Windows failures remain distinct from the configured supported CI
profiles; this release does not claim universal platform qualification.

## Publication boundary

Preparation does not publish the package. Publication requires the reviewed release
commit and annotated tag signed by the authorized owner, main containment, all release
gates and the exact stable-tag OIDC workflow. No local non-dry-run publish is authorized.
Completion additionally requires a clean public-registry consumer verification.
Those publication and consumer checks completed for 2.2.0. Unrelated native proof
work is excluded from this release and package.
