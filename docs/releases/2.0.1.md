# LexRunner 2.0.1 MCP identity correction

- Status: **release candidate**
- Prepared: **2026-08-29**
- Supersedes: **2.0.0**

LexRunner 2.0.1 corrects the product version returned by MCP initialization. The SDK server and the
published `lexrunner-mcp` launcher now read the version from the same package manifest used by the
CLI and registry, so clients can identify the exact installed release.

## Compatibility

This is a patch release. It does not change the 2.0.0 receipt-v2 schema, plan-bound evidence,
timeout precedence, fail-closed container behavior, command names, MCP tool schemas, or authority
boundary. Caller-provided gate evidence remains an unverified observation and cannot grant merge
eligibility; issue #865 still owns the separate plan-pinned authoritative verifier.

## Release verification

The architecture suite initializes the published launcher with the official MCP client transport
and requires `serverInfo.version` to equal `package.json`. The packed-package smoke independently
packs and installs the candidate into a disposable consumer, initializes the installed MCP binary,
checks the same version identity, and verifies all 33 tools including the 18 Attempt and containment
surfaces.

The exact candidate must also pass formatting, typecheck, build, package-boundary validation,
publication dry-run, the hosted test matrix, and independent review before signed-tag publication
through npm's package-scoped GitHub OIDC trusted publisher.
