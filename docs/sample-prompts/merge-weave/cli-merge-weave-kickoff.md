# CLI Merge-Weave Kickoff Prompt (Umbrella Branch + PR, **lex-pr via CLI; MCP-first for git/GitHub**)

---

## Context
You will plan and execute a **merge-weave** into a single umbrella branch and PR using **lex-pr-runner CLI** for the merge-weave primitives. For **git/GitHub** operations, prefer **MCP tools first**, falling back to `gh` CLI, then REST outlines if needed.

- **Discover** open PRs from GitHub; `lex-pr discover` outputs JSON.
- **Plan:** `lex-pr plan --from-github` generates plan.json with dependency suggestions.
- **Order:** `lex-pr merge-order` computes topological sort; outputs levels + execution plan.
- **Create umbrella branch** (`merge-weave-{uuid}`) from default; open draft PR with checklist.
- **Fold PRs:** For each PR (in order), test-merge into umbrella branch, run `lex-pr execute --plan plan.json` for gates.
  - `lex-pr execute` collects gate logs to `.smartergpt.local/artifacts/` (default) and writes summary JSON to stdout.
  - You (agent) capture stdout + logs into fixed session paths.
- **Update umbrella PR body** as PRs fold successfully; **close** folded PRs.
- **Finalize:** Mark umbrella PR ready, merge to default.

**Agent session dir (fixed):** `.smartergpt.local/deliverables/_session`
**lex-pr gate artifacts (default):** `.smartergpt.local/artifacts/` — lex-pr writes detailed gate logs here automatically
**Schema path (fixed):** `schema/plan.schema.json`
**Safety:** No force-push. No history rewrites. Prefer `git revert` for undo.

**Policy highlights:** Dry-run first; proceed-with-siblings; tiny, obvious fixes allowed; umbrella PR closes folded PRs and issues via its body.

## Planner

### Role & Objective
Discover open PRs, generate and validate the merge plan, compute topological order, define gates.

### Allowed Tools
- **lex-pr (CLI only)**: `discover`, `plan --from-github`, `schema validate`, `merge-order`, `execute` (later)
- `jq`, `sed`, `tee` (parse and persist outputs)
- **Forbidden:** force-push, history rewrite

### Steps
1) Initialize session:
```bash
mkdir -p .smartergpt.local/deliverables/_session
```

2) Discover PRs:
```bash
lex-pr discover --json       | tee .smartergpt.local/deliverables/_session/discover.json >/dev/null
```

3) Generate plan.json:
```bash
lex-pr plan --from-github --json       | tee .smartergpt.local/deliverables/_session/plan.json >/dev/null
```

4) Validate plan schema:
```bash
lex-pr schema validate schema/plan.schema.json .smartergpt.local/deliverables/_session/plan.json --json       | tee .smartergpt.local/deliverables/_session/plan.validate.json >/dev/null

jq -e '.valid == true' .smartergpt.local/deliverables/_session/plan.validate.json >/dev/null
```

5) Compute merge order:
```bash
lex-pr merge-order .smartergpt.local/deliverables/_session/plan.json --json       | tee .smartergpt.local/deliverables/_session/merge-order.json >/dev/null
```

6) Write gate definitions (if not generated by plan policy):
```bash
cat > .smartergpt.local/deliverables/_session/gate-definitions.json << 'EOF'
{
  "gates": [
    { "name": "lint", "command": "npm run lint", "required": true, "timeout_seconds": 300 },
    { "name": "type", "command": "npm run typecheck", "required": true, "timeout_seconds": 300 },
    { "name": "unit", "command": "npm test", "required": true, "timeout_seconds": 900 },
    { "name": "determinism", "command": "npm run build && git diff --exit-code", "required": true, "timeout_seconds": 600 }
  ]
}
EOF
```

### Artifacts
- `.smartergpt.local/deliverables/_session/discover.json`
- `.smartergpt.local/deliverables/_session/plan.json`
- `.smartergpt.local/deliverables/_session/plan.validate.json`
- `.smartergpt.local/deliverables/_session/merge-order.json`
- `.smartergpt.local/deliverables/_session/gate-definitions.json`

### Success Criteria
Valid plan, acyclic dependency graph, merge order present, gates defined.

### Message Contract
```json
{
  "agent": "Planner",
  "status": "complete",
  "plan_valid": true,
  "merge_levels": "<int>",
  "artifacts": {
    "plan": ".smartergpt.local/deliverables/_session/plan.json",
    "merge_order": ".smartergpt.local/deliverables/_session/merge-order.json"
  },

}
```

## Umbrella Setup (MCP-first for git/GitHub)

### Role & Objective
Create umbrella branch and draft PR; prepare checklist body.

### Allowed Tools
- **MCP-first git/GitHub**: `mcp:git.fetch|checkout|pull|push|merge`, `mcp:github.pr.create|update|list`
- **Fallbacks**: `gh pr create|view|edit`, REST outlines
- Shell: `jq`, `sed`, `tee`

### Steps
```bash
SESSION_UUID="$(uuidgen | tr 'A-Z' 'a-z')"
UMB_BRANCH="merge-weave-${SESSION_UUID}"
DEF_BRANCH="$(git symbolic-ref --short refs/remotes/origin/HEAD | cut -d'/' -f2 || echo main)"

# MCP-first branch setup
mcp:git.fetch remote="origin"
mcp:git.checkout ref="$DEF_BRANCH"
mcp:git.pull mode="ff-only"
mcp:git.checkout new_branch="$UMB_BRANCH" from="$DEF_BRANCH"
mcp:git.push remote="origin" branch="$UMB_BRANCH" set_upstream=true

# Fallback
git fetch origin && git checkout "$DEF_BRANCH" && git pull --ff-only
git checkout -b "$UMB_BRANCH" && git push -u origin "$UMB_BRANCH"

# Build umbrella body
jq -r '.pullRequests[] | "- [ ] PR #\(.number) (\(.branch // .headRefName))"'       .smartergpt.local/deliverables/_session/discover.json       > .smartergpt.local/deliverables/_session/umbrella-body.md

# MCP-first PR create (draft)
mcp:github.pr.create base="$DEF_BRANCH" head="$UMB_BRANCH"       title="Merge-weave session ${SESSION_UUID}"       body_file=".smartergpt.local/deliverables/_session/umbrella-body.md"       draft=true > .smartergpt.local/deliverables/_session/umbrella.json

# Fallback
gh pr create --base "$DEF_BRANCH" --head "$UMB_BRANCH"       --title "Merge-weave session ${SESSION_UUID}"       --body-file .smartergpt.local/deliverables/_session/umbrella-body.md       --draft | tee .smartergpt.local/deliverables/_session/umbrella.txt
```

### Artifacts
- `.smartergpt.local/deliverables/_session/umbrella-body.md`
- `.smartergpt.local/deliverables/_session/umbrella.json|umbrella.txt`

### Success Criteria
Umbrella branch exists & is pushed; draft PR created and recorded.

## Merge Orchestrator (MCP-first for git/GitHub; lex-pr for gates)

### Role & Objective
Fold PR branches into umbrella, run gates via lex-pr, manage umbrella PR body, close folded PRs, proceed-with-siblings.

### Steps (loop by merge order)
```bash
UMB_PR_NUMBER="$(jq -r '.number // empty' .smartergpt.local/deliverables/_session/umbrella.json       2>/dev/null || gh pr list --head "$UMB_BRANCH" --json number -q '.[0].number')"

# Iterate by merge-pyramid order (sibling-safe)
jq -r '.levels[].nodes[]' .smartergpt.local/deliverables/_session/merge-order.json | while read NODE; do
  PR_NUMBER="${NODE#PR-}"

  # Find branch for PR_NUMBER
  PR_BRANCH="$(jq -r --argjson num "$PR_NUMBER"         '.pullRequests[] | select((.number // .id) == $num) | (.branch // .headRefName)'         .smartergpt.local/deliverables/_session/discover.json)"

  echo "== Folding PR #$PR_NUMBER ($PR_BRANCH) ==" | tee -a .smartergpt.local/deliverables/_session/fold.log

  # MCP-first dry-run merge (no commit)
  mcp:git.checkout ref="$UMB_BRANCH"
  mcp:git.merge ref="origin/${PR_BRANCH}" no_commit=true no_ff=true         | tee -a .smartergpt.local/deliverables/_session/fold.log         || { echo "BLOCKED: conflicts on #$PR_NUMBER" | tee -a .smartergpt.local/deliverables/_session/blockers.md; mcp:git.merge abort=true; continue; }

  # Run gates with lex-pr (stdout JSON captured; detailed artifacts to .smartergpt.local/artifacts/)
  if ! lex-pr execute --plan .smartergpt.local/deliverables/_session/plan.json \
        --json \
        | tee .smartergpt.local/deliverables/_session/gate-result-${PR_NUMBER}.json \
        | jq -e '.execution.failed == false' >/dev/null; then
    echo "BLOCKED: gates failed #$PR_NUMBER" | tee -a .smartergpt.local/deliverables/_session/blockers.md
    mcp:git.merge abort=true || git merge --abort
    continue
  fi

  # Commit the fold-in
  mcp:git.commit message="merge-weave: fold PR #${PR_NUMBER} (${PR_BRANCH}) into ${UMB_BRANCH} (no-ff)"
  mcp:git.push || git push origin "$UMB_BRANCH"

  echo "✓ Folded #$PR_NUMBER" | tee -a .smartergpt.local/deliverables/_session/fold.log

  # Close PR (comment + close)
  mcp:github.pr.comment number="$PR_NUMBER" body="Folded into umbrella PR #${UMB_PR_NUMBER} (${UMB_BRANCH})."
  mcp:github.pr.close number="$PR_NUMBER"
  # Fallbacks
  gh pr comment "$PR_NUMBER" --body "Folded into umbrella PR #${UMB_PR_NUMBER} (${UMB_BRANCH})." || true
  gh pr close "$PR_NUMBER" || true

  # Update umbrella body checklist
  sed -i "s/- \[ \] PR #${PR_NUMBER}/- [x] PR #${PR_NUMBER}/" .smartergpt.local/deliverables/_session/umbrella-body.md
  mcp:github.pr.update number="$UMB_PR_NUMBER" from_file=".smartergpt.local/deliverables/_session/umbrella-body.md" ||       gh pr edit "$UMB_PR_NUMBER" --body-file .smartergpt.local/deliverables/_session/umbrella-body.md
done

# Summary
jq -n       --arg folded "$(grep -c '^✓ Folded' .smartergpt.local/deliverables/_session/fold.log || echo 0)"       --arg blocked "$(grep -c '^BLOCKED' .smartergpt.local/deliverables/_session/blockers.md || echo 0)"       '{folded_prs: ($folded|tonumber), blocked_prs: ($blocked|tonumber), at: now}'       > .smartergpt.local/deliverables/_session/fold-summary.json
```

## Finalization (MCP-first)
```bash
# Ready the umbrella PR if still draft
mcp:github.pr.ready number="$UMB_PR_NUMBER" || gh pr ready "$UMB_PR_NUMBER"

# Merge umbrella PR with a normal merge commit (no squash/rebase)
mcp:github.pr.merge number="$UMB_PR_NUMBER" method="merge" delete_branch=false ||     gh pr merge "$UMB_PR_NUMBER" --merge --delete-branch=false

# Verify
git fetch origin
DEF_BRANCH="$(git symbolic-ref --short refs/remotes/origin/HEAD | cut -d'/' -f2 || echo main)"
git log --oneline "origin/$DEF_BRANCH" | head -10       | tee .smartergpt.local/deliverables/_session/verify.log

# Final summary
jq -n --arg pr "$UMB_PR_NUMBER" --arg ts "$(date -u +%Y-%m-%dT%H:%M:%SZ)"       '{umbrella_pr_merged:true, umbrella_pr_number:$pr, timestamp:$ts, status:"complete"}'       > .smartergpt.local/deliverables/_session/merge-summary.json
```

## Rollback & Recovery (no rewrites)
- Revert a bad fold-in on umbrella: `git revert -m 1 <sha>`; push; update umbrella body; comment on original PR.
- If the fix cannot live in umbrella, reopen the original PR and mark checklist as unchecked with a note.
- Update `recovery.md` and try again.
