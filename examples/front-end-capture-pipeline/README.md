# Front-End Capture Pipeline Examples

This directory contains working examples for the front-end capture pipeline (`lex-pr idea` and `lex-pr create-project` commands).

## Contents

- **`idea-example.sh`** - Shell script demonstrating `lex-pr idea` command
- **`create-project-example.sh`** - Shell script demonstrating `lex-pr create-project` command
- **`idea-dark-mode.json`** - Example Feature Spec v0 (output from `lex-pr idea`)
- **`plan-dark-mode.json`** - Example Execution Plan v1 (output from `lex-pr create-project`)
- **`manual-test-checklist.md`** - Manual testing guide for validation

## Quick Start

### Running the Examples

1. **Ensure prerequisites:**

   ```bash
   # Build the project
   npm run build

   # Set GitHub token (required for Issue creation)
   export GITHUB_TOKEN=ghp_...
   ```

2. **Run the idea example:**

   ```bash
   cd examples/front-end-capture-pipeline
   chmod +x idea-example.sh
   ./idea-example.sh
   ```

3. **Run the create-project example:**
   ```bash
   chmod +x create-project-example.sh
   ./create-project-example.sh
   ```

### Dry Run Mode

Both examples support dry run mode (no GitHub API calls):

```bash
# Dry run - generates spec files only
./idea-example.sh --dry-run
./create-project-example.sh --dry-run
```

## Example Workflow

**End-to-end: Idea → Epic + Sub-Issues**

```bash
# Step 1: Capture idea (generates Feature Spec v0)
lex-pr idea \
  --title "Add dark mode support" \
  --description "Implement theme switcher with light/dark modes"

# Step 2: Generate project (creates Epic + Sub-Issues)
lex-pr create-project \
  --spec .smartergpt.local/deliverables/_session/idea-<timestamp>.json
```

## Understanding the Outputs

### Feature Spec v0 (`idea-dark-mode.json`)

Generated by `lex-pr idea`. Contains:

- Title, description, acceptance criteria
- Optional technical context and constraints
- Repository information
- Timestamp

### Execution Plan v1 (`plan-dark-mode.json`)

Generated by `lex-pr create-project`. Contains:

- Source Feature Spec v0
- Epic definition
- Sub-Issues (feature, testing, docs) with dependencies
